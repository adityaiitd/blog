Provisioned and verified on Ubuntu 24.04 (4 vCPU, 15 GiB). `forge/data/toolchain.json`
is regenerated by `python3 forge/toolchain.py` and is the machine-readable record.

| Tool | Version | Notes |
|---|---|---|

## FEMM under Wine

Two problems had to be solved, both recorded here so the setup is reproducible:

1. The FEMM installer is a 32-bit Inno Setup binary. Rather than depend on the
   installer running, `innoextract` unpacks it natively on Linux and the x86-64
   payload is copied to `~/.wine/drive_c/femm42/`.
2. Both `femm.exe` and the solver kernel `fkn.exe` import `mfc90.dll`, which
   Wine does not ship. `winetricks -q vcrun2008` supplies it.

The toolchain probe does not trust file presence. `probe_femm_functional` runs a
magnetostatic solve of a 2 mm-radius copper conductor and compares the
resistance FEMM reports against the analytic value, currently agreeing to
better than 0.02%. If that check fails, `field_2d_fea` goes false and every
field quantity is marked UNVERIFIED downstream.

## Browser retrieval

Chrome runs headful with a dedicated `--user-data-dir` and
`--remote-allow-origins=*`; since Chrome 136 the default profile ignores
`--remote-debugging-port`. Observed behaviour against the sources this project
needs:

| Source | curl | headful Chrome |
|---|---|---|
| TDK ferrite catalog | 403 | 200, ~1 MB of content |
| OCP Diablo 400 | 403 | managed challenge, recorded as a manual gate |
| EPC white paper, TI Power Tip, Magnetics catalog | 200 | not needed |

The OCP result is the designed outcome, not a failure: the session detects the
interstitial and opens a manual gate rather than attempting to defeat it.
